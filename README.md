# typepper releases

Builds of **typepper**, a spicy little typing game for your terminal and browser.

- **Play in your browser:** https://leodiegues.com/typepper/
- **Install in your terminal** (macOS, Linux):

  ```sh
  curl -LsSf https://leodiegues.com/typepper/install.sh | sh
  ```

  Windows (PowerShell):

  ```powershell
  powershell -ExecutionPolicy Bypass -c "irm https://github.com/leodiegues/typepper-releases/releases/latest/download/typepper-installer.ps1 | iex"
  ```

Binaries for every version are under [Releases](https://github.com/leodiegues/typepper-releases/releases).
